# 1. Windows Temp Folder পরিচিতি

## উদ্দেশ্য
`%TEMP%` কী, কোথায় থাকে, কী ধরনের ফাইল সেখানে জমা হয়, এবং ফরেনসিক/সিকিউরিটি
দৃষ্টিকোণ থেকে কেন এটি গুরুত্বপূর্ণ — তা বোঝা।

## ১.১ `%TEMP%` কী?

`%TEMP%` একটি এনভায়রনমেন্ট ভ্যারিয়েবল যা অপারেটিং সিস্টেম ও অ্যাপ্লিকেশনগুলোকে
জানায় সাময়িক (temporary) ফাইল কোথায় রাখতে হবে।

```powershell
[Environment]::GetEnvironmentVariable("TEMP")
# অথবা সরাসরি
$env:TEMP
```

সাধারণ পাথ (per-user):

```
C:\Users\<user>\AppData\Local\Temp
```

## ১.২ টেম্প ফোল্ডারের ধরন

| টাইপ | পাথ | ব্যবহারকারী |
|------|-----|-------------|
| User Temp | `%TEMP%` = `C:\Users\<user>\AppData\Local\Temp` | নির্দিষ্ট ইউজার-এর প্রসেসগুলো |
| System Temp | `C:\Windows\Temp` | SYSTEM কনটেক্সটে চলা সার্ভিস/প্রসেস |

## ১.৩ টেম্পে সাধারণত কী কী ফাইল আসে

- **ইনস্টলার আর্টিফ্যাক্ট** — MSI/EXE ইনস্টলারের এক্সট্র্যাক্ট করা ফাইল
- **ব্রাউজার/অফিস ক্যাশ** — অস্থায়ী ডাউনলোড, অটোসেভ ফাইল
- **গেম/অ্যাপ ক্যাশ** — শেডার ক্যাশ, আপডেট প্যাকেজ
- **ডাউনলোডেড এক্সিকিউটেবল/ড্রপার** — অনেক ম্যালওয়্যার/ইনস্টলার প্রথমে টেম্পে
  পেলোড এক্সট্র্যাক্ট করে, তারপর রান করে
- **লগ, ক্র্যাশ ডাম্প, জিপ/আর্কাইভ** — ডিবাগিং বা আনপ্যাকিং-এর সময় তৈরি হয়

## ১.৪ কেন এটি গুরুত্বপূর্ণ

1. **ইনসিডেন্ট রেসপন্স:** অনেক ম্যালওয়্যার/PUA প্রথম ধাপে টেম্পে রান হয়ে পরে
   নিজেকে ডিলিট করে ফেলে — তাই টেম্প হলো একটি হাই-ভ্যালু আর্টিফ্যাক্ট সোর্স।
2. **অ্যান্টি-চিট অ্যানালাইসিস:** গেম চিট/ইনজেক্টর প্রায়ই টেম্পে ড্রপ হয়, রান হয়,
   এবং ইনজেকশনের পর ডিলিট হয়ে যায়।
3. **সাধারণ ট্রাবলশুটিং:** ব্যবহারকারীর ডিলিট হওয়া গুরুত্বপূর্ণ অস্থায়ী ফাইল
   (যেমন অটোসেভ ডকুমেন্ট) রিকভার করা।
