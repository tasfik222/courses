# 9. বোনাস: ভলিউম শ্যাডো কপি ও অন্যান্য আর্টিফ্যাক্ট

## উদ্দেশ্য
Temp-এর বাইরেও Windows-এ কোন কোন আর্টিফ্যাক্ট ফরেনসিক ইনভেস্টিগেশনে কাজে
লাগে — তার একটি হাই-লেভেল পরিচিতি।

## ৯.১ Volume Shadow Copy (VSS)

VSS হলো Windows-এর একটি বিল্ট-ইন স্ন্যাপশট মেকানিজম, যা মূলত System
Restore/ব্যাকআপের জন্য ব্যবহৃত হয়। এতে ফাইলের পুরনো ভার্সন সংরক্ষিত থাকতে
পারে — এমনকি ফাইলটি বর্তমানে ডিলিট থাকলেও।

```powershell
# বিদ্যমান শ্যাডো কপি তালিকা দেখা
vssadmin list shadows
```

শ্যাডো কপি থেকে ফাইল এক্সট্র্যাক্ট করা একটি অ্যাডভান্সড বিষয় এবং সাধারণত
বিশেষায়িত টুল (যেমন ShadowExplorer বা `mklink` দিয়ে shadow ভলিউম মাউন্ট করা)
প্রয়োজন হয়। এই কোর্স শুধু ধারণাগত পরিচিতি দেয়।

## ৯.২ Prefetch

`C:\Windows\Prefetch\` ফোল্ডারে থাকা `.pf` ফাইলগুলো রেকর্ড রাখে কোন
এক্সিকিউটেবল কতবার এবং সর্বশেষ কখন রান হয়েছিল — এমনকি এক্সিকিউটেবলটি নিজে
পরে ডিলিট হয়ে গেলেও।

```powershell
Get-ChildItem C:\Windows\Prefetch\*.pf
```

এটি টেম্প থেকে রান হওয়া কোনো প্রোগ্রামের **এক্সিকিউশন প্রমাণ** হিসেবে
টেম্প-আর্টিফ্যাক্টের সাথে কোরিলেট করা যায়।

## ৯.৩ ShimCache / AmCache

- **ShimCache (AppCompatCache):** রেজিস্ট্রিতে থাকা এক্সিকিউশন-সম্পর্কিত
  মেটাডেটা (সবসময় "রান হয়েছে" প্রমাণ করে না, তবে ইঙ্গিত দেয়)।
- **AmCache** (`C:\Windows\AppCompat\Programs\Amcache.hve`): ফাইল হ্যাশ,
  পাথ, প্রথম-দেখা টাইমস্ট্যাম্প সহ আরও বিস্তারিত তথ্য রাখে।

এগুলো বিশ্লেষণের জন্য সাধারণত বিশেষায়িত পার্সার (যেমন `AmcacheParser`,
Eric Zimmerman-এর টুলসেট) ব্যবহার করা হয় — এই কোর্সের সুযোগের বাইরে, তবে
পরবর্তী ধাপ হিসেবে সুপারিশ করা হলো।

## ৯.৪ SRUM (System Resource Usage Monitor)

`C:\Windows\System32\sru\SRUDB.dat` — নেটওয়ার্ক ব্যবহার, অ্যাপ চালানোর
সময়কাল ইত্যাদির ঐতিহাসিক রেকর্ড রাখে। কোনো প্রসেস কখন সক্রিয় ছিল তার
টাইমলাইন যাচাইয়ে সহায়ক।

## ৯.৫ Windows Event Logs

গুরুত্বপূর্ণ Event ID (Security/Sysmon লগে):

| Event ID | অর্থ |
|----------|------|
| 4688 | নতুন প্রসেস তৈরি হয়েছে (Security log, audit সক্রিয় থাকলে) |
| 4663 | অবজেক্ট অ্যাক্সেস (ফাইল, audit সক্রিয় থাকলে) |
| Sysmon 1 | প্রসেস ক্রিয়েশন (কমান্ড লাইন-সহ, বিস্তারিত) |
| Sysmon 11 | ফাইল তৈরি |

```powershell
Get-WinEvent -LogName Security -MaxEvents 50 |
    Where-Object { $_.Id -eq 4688 }
```

## ৯.৬ সংক্ষিপ্তসার — একটি সম্পূর্ণ ফরেনসিক ছবি

```
Temp Folder (এই কোর্সের মূল ফোকাস)
   +
Prefetch (কী রান হয়েছিল)
   +
ShimCache/AmCache (কবে প্রথম দেখা গিয়েছিল)
   +
Event Logs (কে/কখন/কীভাবে)
   +
VSS/SRUM (হিস্টোরিক্যাল স্ন্যাপশট)
   =
একটি সম্পূর্ণ ইনসিডেন্ট টাইমলাইন
```

## কোর্স সম্পন্ন! 🎓

এই কোর্স শেষ করে আপনি এখন পারবেন:
- Windows Temp ফোল্ডার থেকে লাইভ ডেটা কালেক্ট করতে
- winfr দিয়ে ডিলিটেড ফাইল রিকভার করতে
- রিকভার করা ফাইল ট্রায়াজ ও ভেরিফাই করতে
- পুরো প্রক্রিয়া অটোমেট করে একটি রিপোর্টেবল ওয়ার্কফ্লো তৈরি করতে
- অন্যান্য Windows আর্টিফ্যাক্টের সাথে টেম্প-ডেটা কোরিলেট করার ধারণা রাখতে

**পরবর্তী পদক্ষেপ:** SANS FOR500 (Windows Forensics) বা অনুরূপ কোর্স, এবং
Eric Zimmerman-এর ফরেনসিক টুলসেট এক্সপ্লোর করা।
