# 8. ল্যাব এক্সারসাইজ ও চ্যালেঞ্জ

> প্রতিটি ল্যাব শুরুর আগে একটি ক্লিন VM স্ন্যাপশট নিশ্চিত করুন
> (দেখুন [lab-setup.md](../lab-setup.md))।

## ল্যাব ১ — বেসিক ডিলিট ও রিকভারি

**লক্ষ্য:** টেম্প ↔ ডিলিট ↔ রিকভার ↔ ভেরিফাই — সম্পূর্ণ চক্র হাতে-কলমে করা।

### ধাপসমূহ

1. টেম্পে ৫টি টেস্ট ফাইল তৈরি করুন:
   ```powershell
   1..5 | ForEach-Object {
       "Test content $_" | Out-File "$env:TEMP\test_$_.tmp"
   }
   ```
2. প্রতিটি ফাইলের হ্যাশ নোট করুন:
   ```powershell
   Get-ChildItem "$env:TEMP\test_*.tmp" | Get-FileHash
   ```
3. ফাইলগুলো স্থায়ীভাবে ডিলিট করুন (Recycle Bin এড়িয়ে):
   ```powershell
   Get-ChildItem "$env:TEMP\test_*.tmp" | Remove-Item -Force
   ```
4. `winfr` দিয়ে রিকভার করুন (দেখুন চ্যাপ্টার ৪)।
5. রিকভার করা ফাইলের হ্যাশ বের করে ধাপ ২-এর হ্যাশের সাথে মেলান।

**সাফল্যের মাপকাঠি:** সব ৫টি ফাইলের হ্যাশ হুবহু মিলে যাওয়া।

## ল্যাব ২ — এক্সিকিউটেবল আর্টিফ্যাক্ট রিকভারি ও PE চেক

**লক্ষ্য:** exe/dll-জাতীয় ফাইল রিকভার করে স্ট্যাটিক ট্রায়াজ করা।

### ধাপসমূহ

1. একটি নিরীহ, স্বাক্ষরযুক্ত সিস্টেম টুল (যেমন `notepad.exe`-এর একটি কপি)
   টেম্পে কপি করুন এবং র‍্যান্ডম নাম দিন (শুধু প্র্যাকটিসের জন্য — আসল
   ম্যালওয়্যার নয়):
   ```powershell
   Copy-Item C:\Windows\System32\notepad.exe "$env:TEMP\a1b2c3d4.exe"
   ```
2. ফাইলটি ডিলিট করুন।
3. winfr দিয়ে রিকভার করুন।
4. `sigcheck` দিয়ে ডিজিটাল সিগনেচার যাচাই করুন (চ্যাপ্টার ৫)।
5. ম্যাজিক বাইট চেক করে নিশ্চিত করুন এটি সত্যিই একটি PE ফাইল।

গাইড: [`labs/lab-02/`](../labs/lab-02/)

## ল্যাব ৩ — সম্পূর্ণ কেস স্টাডি ওয়ার্কফ্লো

**সিনারিও:** আপনাকে জানানো হয়েছে একটি টেস্ট VM-এ "সন্দেহজনক কার্যকলাপ"
ঘটেছিল গত ২৪ ঘণ্টায় এবং সংশ্লিষ্ট ফাইলগুলো টেম্প থেকে ডিলিট হয়ে গেছে।
আপনার কাজ সম্পূর্ণ ওয়ার্কফ্লো চালিয়ে একটি রিপোর্ট জমা দেওয়া।

### ধাপসমূহ

1. (ইনস্ট্রাক্টর/সেলফ-সেটআপ) টেম্পে ৩-৫টি বিভিন্ন এক্সটেনশনের (`.exe`,
   `.zip`, `.dat`) টেস্ট ফাইল তৈরি করুন ও ডিলিট করুন — টাইমস্ট্যাম্প ভিন্ন
   ভিন্ন রাখুন।
2. `scripts/full-temp-workflow.ps1` চালান।
3. তৈরি হওয়া রিপোর্ট (JSON/CSV) পর্যালোচনা করুন:
   - টাইমলাইন কি প্রত্যাশিত ক্রম দেখাচ্ছে?
   - এক্সটেনশন ব্রেকডাউন কি সঠিক?
   - "সন্দেহজনক প্যাথ" হিউরিস্টিক কোনো false positive/negative দেখাচ্ছে কি?
4. এক পাতার সারাংশ লিখুন (কোন ফাইল রিকভার হলো, কোনটি হলো না, এবং কেন —
   চ্যাপ্টার ৩-এর থিওরির সাথে সম্পর্কিত করে)।
